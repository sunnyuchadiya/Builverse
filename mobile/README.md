# 📱 BuildVerse Mobile App (React Native Setup Guide)

Welcome to the **BuildVerse Mobile App** built with **React Native (Expo SDK 51)**. This guide is written specially for developers to help you set up, test, run, and build the mobile app on Android/iOS step-by-step.

---

## 🌟 Overview
The React Native mobile app brings full feature parity with the BuildVerse platform:
1. **Dynamic Light & Dark Theme Mode**: Toggle anytime from profile or settings.
2. **Project CRUD & To-Do Tracker**: Create, view, update, complete, and delete projects with task priority management (`HIGH`, `MEDIUM`, `LOW`).
3. **Team Member Invites & Auto Group Chat**: Invite members to projects with automatic project team group chats (`<Project Name> Team`).
4. **Community Hub & Trending Forum**: WhatsApp-style direct messaging, group channels, and topic discussion forums.
5. **PDF Certificate Diploma Generator**: Download verifiable completion certificates.
6. **GitHub OAuth Auth**: Interactive GitHub login with live repository reflection.

---

## ⚡ Quick Start (Run Locally)

### 1. Install Dependencies
```bash
cd mobile
npm install
```

### 2. Run Dev Server
```bash
npm start
```
- Press **`a`** to open in Android Emulator / Phone via Expo Go.
- Press **`w`** to open in Web Browser.
