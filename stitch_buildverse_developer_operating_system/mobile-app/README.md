# BuildVerse Mobile

React Native + JavaScript conversion of the Stitch pages inside `stitch_buildverse_developer_operating_system`.

## Included screens

- `Login`
- `Register`
- `Home` dashboard
- `Projects`
- `ProjectDetails`
- `Groups` community hub
- `Chat`
- `Profile`

## Navigation links

- Auth screens link into the main app.
- Bottom tabs link `Home`, `Projects`, `Groups`, `Chat`, and `Profile`.
- Dashboard and Projects cards open `ProjectDetails`.
- Community and Profile actions route to related screens.

## Run

Install dependencies inside `mobile-app`, then start Expo:

```bash
npm install
npm start
```
